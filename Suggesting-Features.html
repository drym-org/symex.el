9.1.2 Suggesting Features ¶

Feature requests are welcome — just create an issue describing the functionality you seek.

If you’d like to take matters into your own hands and submit a PR, that’s even better! You’re still welcome to start the process with an issue to solicit input from other Symex contributors and users, so that your PR can be informed by these perspectives. But if you feel you already have a good idea of what you’re going for, then by all means, jump straight to the PR, and feel free to reach out for help.
